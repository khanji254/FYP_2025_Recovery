\section{Remaining Work and Timeline}
\label{sec:remaining}

This chapter outlines the remaining tasks required to complete the project, along with the proposed timeline for completion. Work is organized into major phases with clear milestones and deliverables.

\subsection{Outstanding Tasks}

\subsubsection{Mechanical System Completion}

\textbf{Avionics Sled Fabrication:}
\begin{itemize}
    \item Complete 3D printing of avionics sled in PETG
    \item Post-processing (deburring, dimensional verification)
    \item Fit-check with electronic components
    \item Integration with airframe mounting points
    \item Vibration isolation validation testing
\end{itemize}

\textbf{Explosion Cap Fabrication:}
\begin{itemize}
    \item Machine aluminum explosion cap components
    \item Install O-ring sealing
    \item Pressure testing to validate containment (5--10 bar)
    \item Integration with airframe bulkhead
    \item Static fire testing with various charge masses
\end{itemize}

\textbf{Battery Holder and Mounting Hardware:}
\begin{itemize}
    \item 3D print battery holder with retention straps
    \item Fabricate cable management brackets
    \item Assemble complete mechanical system
    \item Weight and center-of-gravity verification
\end{itemize}

\subsubsection{Electrical System Completion}

\textbf{PCB Assembly and Testing:}
\begin{itemize}
    \item Receive PCBs from fabrication house (expected [date])
    \item Visual inspection and continuity testing
    \item Component soldering (surface mount and through-hole)
    \item Power-on testing (voltage rails, current consumption)
    \item Functional testing of all circuits (PWM, ADC, UART, I$^2$C)
    \item Integration with ESP32 and XBee modules
\end{itemize}

\textbf{System Integration:}
\begin{itemize}
    \item Install PCB in avionics sled
    \item Route and secure all wiring (battery, igniters, sensors)
    \item Install antennas (XBee, GPS) with optimal placement
    \item Secure GPS and IMU modules
    \item Final mechanical integration with airframe
\end{itemize}

\subsubsection{Firmware Completion}

\textbf{Flight State Machine:}
Implement complete state machine managing flight phases:
\begin{itemize}
    \item \textbf{Pre-launch State:} Battery monitoring, continuity checks, GPS lock, telemetry link verification
    \item \textbf{Ready State:} Armed for launch, awaiting liftoff detection
    \item \textbf{Powered Ascent:} Detect motor burnout, transition to coasting
    \item \textbf{Coasting:} Monitor altitude, detect apogee
    \item \textbf{Apogee Detection:} Trigger drogue deployment
    \item \textbf{Descent:} Monitor altitude for main deployment altitude
    \item \textbf{Main Deployment:} Trigger main parachute at 300--500 m AGL
    \item \textbf{Landed:} Continue telemetry for vehicle location
\end{itemize}

\textbf{Apogee Detection Algorithm:}
Implement robust apogee detection using sensor fusion:
\begin{itemize}
    \item Barometric altitude rate-of-change (primary method)
    \item Accelerometer velocity integration (backup method)
    \item Timing guard (minimum time from liftoff: 10 seconds)
    \item Altitude guard (minimum altitude: 100 m AGL)
\end{itemize}

\textbf{Deployment Trigger Logic:}
\begin{itemize}
    \item Drogue deployment: At apogee detection
    \item Main deployment: At 300--500 m AGL (configurable threshold)
    \item Manual override capability via ground station command
    \item Backup timer-based deployment (if sensors fail)
\end{itemize}

\textbf{Data Logging:}
\begin{itemize}
    \item Implement SD card logging subsystem
    \item Log all sensor data at 10 Hz throughout flight
    \item Log state transitions and deployment events
    \item File management (pre-flight, flight, post-flight files)
\end{itemize}

\textbf{Ground Station Software:}
\begin{itemize}
    \item Develop ground station GUI (Python + PyQt or similar)
    \item Real-time telemetry display (altitude, velocity, GPS, battery status)
    \item Launch inhibit status indicators
    \item Deployment command interface
    \item Data logging and post-flight analysis tools
\end{itemize}

\subsubsection{Testing and Validation}

\textbf{Charge Characterization Testing:}
Critical experimental work to establish charge-to-force relationships:
\begin{itemize}
    \item Design and fabricate test fixture with load cell
    \item Test varying charge masses (1--5 grams, 0.5 gram increments)
    \item Record peak force, rise time, pressure-time profiles
    \item Statistical analysis with multiple replicates per charge mass
    \item Determine optimal charge sizing for reliable deployment without over-stress
\end{itemize}

\textbf{System Integration Testing:}
\begin{itemize}
    \item Complete electrical system functionality test
    \item Telemetry link verification at extended range
    \item GPS tracking accuracy validation
    \item Battery endurance testing (power consumption profiling)
    \item Continuity detection under various fault scenarios
\end{itemize}

\textbf{Ignition System Validation:}
\begin{itemize}
    \item Multiple PWM ignition tests with flight-configuration wiring
    \item Verify reliable ignition with flight battery under load
    \item Test ignition reliability after mechanical shock/vibration
    \item Validate ignition timing repeatability
\end{itemize}

\textbf{Mechanical Validation:}
\begin{itemize}
    \item Drop testing to simulate deployment shock (50--100G)
    \item Verify avionics mounting integrity after shock
    \item Check for loose connections or component damage
    \item Vibration table testing (if equipment available)
\end{itemize}

\textbf{Full System Ground Tests:}
\begin{itemize}
    \item Complete integrated system test with all subsystems
    \item Simulated flight profile test (software-triggered deployment sequence)
    \item Telemetry range validation with flight antenna configuration
    \item Deployment force testing with final charge sizing
    \item Multiple successful deployment tests required for flight qualification
\end{itemize}

\textbf{Flight Readiness Review:}
\begin{itemize}
    \item Document all test results
    \item Risk assessment and mitigation strategies
    \item Final pre-flight checklist development
    \item Safety review with Nakuja team and launch authority
    \item Go/No-go decision criteria
\end{itemize}

\subsection{Risk Assessment and Mitigation}

\subsubsection{Technical Risks}

\textbf{Risk 1: PCB Fabrication Defects}
\begin{itemize}
    \item \textit{Probability:} Low
    \item \textit{Impact:} High (project delays)
    \item \textit{Mitigation:} Thorough inspection on receipt, order spare PCBs, maintain breadboard backup for testing
\end{itemize}

\textbf{Risk 2: Deployment Force Unpredictability}
\begin{itemize}
    \item \textit{Probability:} Medium
    \item \textit{Impact:} High (failed deployment or airframe damage)
    \item \textit{Mitigation:} Comprehensive charge characterization testing, multiple test deployments, conservative charge sizing with safety margin
\end{itemize}

\textbf{Risk 3: Telemetry Link Loss}
\begin{itemize}
    \item \textit{Probability:} Low--Medium
    \item \textit{Impact:} Medium (loss of real-time data, vehicle harder to locate)
    \item \textit{Mitigation:} SD card data logging backup, GPS coordinates in last telemetry packet, audible beacon for locating
\end{itemize}

\textbf{Risk 4: Software Bugs in Flight Code}
\begin{itemize}
    \item \textit{Probability:} Medium
    \item \textit{Impact:} High (failed deployment, mission loss)
    \item \textit{Mitigation:} Extensive ground testing, simulated flight profiles, code review, backup timer-based deployment
\end{itemize}

\textbf{Risk 5: Mechanical Failure Under Launch Loads}
\begin{itemize}
    \item \textit{Probability:} Low
    \item \textit{Impact:} High (electronics damage, mission failure)
    \item \textit{Mitigation:} FEA validation, drop testing, vibration testing if available, redundant fastening
\end{itemize}

\subsubsection{Schedule Risks}

\textbf{Risk 1: PCB Delivery Delays}
\begin{itemize}
    \item \textit{Probability:} Medium
    \item \textit{Impact:} Medium (schedule delay)
    \item \textit{Mitigation:} Place PCB order early, maintain breadboard prototype for continued development
\end{itemize}

\textbf{Risk 2: Component Procurement Delays}
\begin{itemize}
    \item \textit{Probability:} Low (most components already received)
    \item \textit{Impact:} Medium
    \item \textit{Mitigation:} Order remaining components immediately, identify alternative suppliers
\end{itemize}

\textbf{Risk 3: Test Facility Availability}
\begin{itemize}
    \item \textit{Probability:} Medium
    \item \textit{Impact:} Low--Medium
    \item \textit{Mitigation:} Schedule test facility access early, coordinate with Nakuja team
\end{itemize}
